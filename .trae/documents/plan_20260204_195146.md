# Flutter 重写 FlyNarwhal 计划 (包含登录页)

本计划旨在将 Kotlin Desktop 应用 `FlyNarwhal` 使用 Flutter 和 `fluent_ui` 框架重写到 `/Users/jankinwu/Desktop/workspace/flutter/fly-narwhal-flutter` 目录下。优先实现登录页、首页和媒体库页，复刻原版样式、动画及业务逻辑，并使用 Riverpod 进行状态管理。

## 1. 项目初始化与配置

* **初始化 Flutter 项目**: 在目标目录创建新的 Flutter 项目（如果为空）。

* **配置依赖 (`pubspec.yaml`)**:

  * UI 框架: `fluent_ui` (本地路径: `/Users/jankinwu/Desktop/workspace/github/fluent_ui`)

  * 状态管理: `flutter_riverpod`, `riverpod_annotation`

  * 路由管理: `go_router`

  * 网络请求: `dio`

  * 图片加载: `cached_network_image`

  * JSON 序列化: `json_annotation`, `json_serializable`, `build_runner`

  * 本地存储: `shared_preferences` (用于存储登录历史、Token)

  * 模糊效果: `flutter_acrylic` (可选，用于登录页毛玻璃效果)

## 2. 架构设计

采用 Feature-first 或 Layer-first 结构，结合 Riverpod：

* `lib/data`: 数据层 (Models, API Client, Repositories, LocalStorage)

* `lib/providers`: 状态管理层 (Riverpod Providers)

* `lib/ui`: 界面层

  * `widgets`: 通用组件 (如 `MoviePoster`, `MediaLibCard`)

  * `screens`: 页面 (`LoginScreen`, `HomeScreen`, `MediaLibraryScreen`)

  * `navigation`: 路由配置 (`AppRouter`，包含登录守卫)

## 3. 核心功能实现步骤

### 第一阶段：基础框架与数据层

* 实现 `main.dart` 入口，配置 `ProviderScope`。

* 配置 `FluentApp` 和 `GoRouter`。

* 封装 `DioClient`，实现基本的网络请求拦截器（Token注入）。

* 封装 `PreferencesManager`，用于存取登录历史和用户偏好。

### 第二阶段：登录页 (Login Page) 实现

* **参考**: `LoginScreen.kt`, `LoginViewModel.kt`

* **UI 实现**:

  * **背景**: 全屏背景图 + 毛玻璃/Acrylic 效果容器。

  * **表单**:

    * Host/IP 输入框 (支持历史记录下拉或侧边栏)。

    * 端口输入框 (数字输入)。

    * 用户名/密码输入框 (密码可见性切换)。

    * 开关: 记住密码、HTTPS、NAS 登录模式。

  * **侧边栏**: `HistorySidebar`，从左侧滑出，展示历史登录记录。

* **逻辑实现**:

  * 创建 `LoginViewModel` (Riverpod)，处理登录请求、历史记录保存、Token 存储。

  * 实现登录成功后的路由跳转（跳转至首页）。

### 第三阶段：App 主框架与首页 (Home Page)

* **UI 实现**:

  * `MainLayout`: 包含 `NavigationView` (侧边栏导航)。

  * `HomeScreen`:

    * `MediaLibCardRow`: 横向滚动展示媒体库。

    * `RecentlyWatched`: 横向滚动展示“继续观看”。

    * `MediaLibGallery`: 动态展示各媒体库内容。

* **逻辑实现**:

  * `HomeViewModel`: 获取聚合数据。

  * 实现退出登录逻辑。

### 第四阶段：媒体库页 (Media Library)

* **UI 实现**:

  * `MediaLibraryScreen`:

    * 头部: 标题、筛选按钮 (`FilterButton`)、排序按钮 (`SortFlyout`)。

    * 列表: `GridView.builder` 实现自适应网格布局。

    * 筛选面板: `FilterBox` (展开/收起动画)。

    * 组件: `MoviePoster` (海报、评分、状态图标)。

* **逻辑实现**:

  * `MediaLibraryViewModel`: 处理分页加载、筛选条件构造、排序逻辑。
